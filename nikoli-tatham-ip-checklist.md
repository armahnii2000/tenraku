# Falling — Nikoli / Tatham IP checklist (research note, 2026-10-20)

Not legal advice. Prepared after George's 2026-10-20 side-chat questions:
"Am I allowed to use Nikoli puzzles in games for money?" and the
Tenraku (転落) title exploration. This note only adds verified sources
and one new fact (Tatham's licence terms) to the answer already given
in chat — it does not replace it.

## What is now source-backed

1. **Sudoku's name: trademark in Japan only, by Nikoli's founder's own account.**
   - Maki Kaji, in his Japan Policy Forum essay: "The name sudoku was
     registered as a trademark in Japan alone" and "the reason why
     sudoku got this popular is probably because it was not trademarked"
     overseas.
     Source: https://www.japanpolicyforum.jp/pdf/2015/no26/DJweb_26_cul_01.pdf
   - A New York Times profile reprint records the same point, plus:
     Kaji said Nikoli "does not plan to trademark other new games,
     either, in hopes this will also help them take off."
     Source: https://www.conceptispuzzles.com/zh/forum/printable.aspx?m=2362&mpage=1
   - Practical read: descriptive use of puzzle-type names (Masyu,
     Nurikabe, Tentai Show/Galaxies, Slitherlink, Hashiwokakero) in a
     US-sold game is low-risk; branding a whole product with one of
     those names, or selling under "Sudoku" in Japan, is the trap.
     This matches the answer already given in chat.

2. **Tatham's collection is MIT-licensed — code included (NEW).**
   - Tatham's own introduction: the games "were mostly not my
     invention; they are re-implementations of existing game concepts"
     and "This collection is distributed under the MIT licence … you
     can do pretty much anything you like with the game binaries or
     the code, except pretending you wrote them yourself, or suing me
     if anything goes wrong."
     Source: https://www.chiark.greenend.org.uk/~sgtatham/puzzles/doc/intro.html
     Collection home: https://www.chiark.greenend.org.uk/~sgtatham/puzzles/
   - Practical read: unlike Nikoli's published grids, Tatham's
     generators/solvers for Loopy, Pearl, Galaxies, Black Box etc.
     can legally be used in a commercial game, with the MIT copyright
     notice kept. That is a stronger position than "learn the rules
     and re-implement" — the code itself is reusable.

3. **Still NOT free to use (unchanged from the chat answer):**
   - Nikoli's actual published puzzle grids, rule-book text, or art.
   - Any puzzle instance must be George's own / generated.

4. **"Tenraku" as a title — negative search result only.**
   - Web searches on 2026-10-20 for a commercial game titled
     "Tenraku" (Steam / itch.io / puzzle game) returned no such game;
     results were unrelated near-matches (Game Tengoku, Tenkyu).
   - This is NOT a trademark clearance — no USPTO/JPO register search
     was done. It only means no prominent game is already using the
     exact name, as far as a web search can show.

## One-line rule for Falling
Borrow rule ideas freely; generate your own puzzles (or reuse
Tatham's MIT code with attribution); write your own rule text;
keep Nikoli names descriptive, never the product brand; keep
"Tenraku / 闇への転落" as a subtitle candidate, not a cleared title.
